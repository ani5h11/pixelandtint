Tint Mask Polygon Editor

How to use:
  1. Click points on the car windows to trace their shape perfectly.
  2. Press Close Path when you finish outlining a window (e.g. front window).
  3. Start clicking again to draw the next window (e.g. rear window).
  4. Copy the generated SVG code and paste it into WINDOW_MASK_PATH in TintDarknessVisualizer.tsx.
